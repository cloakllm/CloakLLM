# Contributing to CloakLLM

Thanks for your interest in contributing to CloakLLM!

## Where to Contribute

CloakLLM is split across several repositories. Code contributions should go to the specific SDK or server repo:

| Repo | What it covers |
|------|---------------|
| [CloakLLM-PY](https://github.com/cloakllm/CloakLLM-PY) | Python SDK — detection, tokenization, audit, LiteLLM middleware |
| [CloakLLM-JS](https://github.com/cloakllm/CloakLLM-JS) | JavaScript SDK — detection, tokenization, audit, OpenAI/Vercel middleware |
| [CloakLLM-MCP](https://github.com/cloakllm/CloakLLM-MCP) | MCP server — Claude Desktop integration |

Each repo has its own `CONTRIBUTING.md` with setup instructions, test commands, and project structure.

## This Repo (Hub)

This repository contains the project overview, architecture docs, and cross-repo links. Contributions here are welcome for:

- Improving documentation or diagrams
- Fixing broken links
- Updating the feature matrix or comparisons

## Reporting Issues

If you're unsure which repo an issue belongs to, open it here and we'll triage it.
